Coffee Shop database project. Work in progress.

These are the relevant files for the project:

- **ER_model.png**: This file has the image of the ER model for the database.
- **frontend folder**: Using React used to display the frontend. Need to download Node.js to run locally. To run cd frontend, then npm start in terminal
- **backend folder**: Using Django and Django Rest Framework to manage API calls to the backend and database. To install
the packages I used, pip install -r backend/requirements_backend.txt. Then, in the backend folder, you have to run python manage.py startserver
to start the SQL server. Then, you can make calls to the API using the REST protocol (still working on this).
